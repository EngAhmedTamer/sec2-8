02

The Big Question

In Lesson 2-1 you learned how encryption and authentication protect communication and accounts. Now we protect the network itself: organizations store important data and services, and attackers try to reach them. A single protection that fails can expose everything.

MAIN QUESTION

How can an organization design its network so it stays protected even if one defense is breached?

Key idea: The strongest network security comes from layering controls — Defense in Depth.

03

A Defended Network at a Glance

Follow the traffic: remote staff use an encrypted VPN tunnel, public visitors reach only the DMZ, and the internal network stays behind a second firewall.

Zero Trust applies everywhere: every access is verified, whether it comes from outside or inside.

10

Summary — Main Question Answered

  • An organization stays safe by using multiple layers: perimeter firewall + VPN for remote access + DMZ for public services + endpoint protection + continuous verification.
  • The firewall filters traffic by rules; the VPN protects remote access; the DMZ isolates public services from the internal network.
  • Zero Trust: nothing is trusted automatically — verify every access, every time.
